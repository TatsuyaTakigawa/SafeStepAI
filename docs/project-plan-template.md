## 1. プロジェクト概要

### 1.1 背景・課題

対象とする課題、利用環境、関係者を記載する。未確認の現状・統計情報は事実として断定しない。

### 1.2 目的

プロジェクトで作成するシステムと、その目的を簡潔に記載する。

### 1.3 成功条件

評価可能な条件と測定方法を記載する。目標値、実測値、未評価を区別する。

## 2. システム概要と実装ベースライン

### 2.1 構成

SafeStep AIを例とする場合、検知端末（Raspberry Pi上のPython / YOLO）からHTTP APIを通じてダッシュボード側（PHP / Apache、MariaDB）へイベントを送る構成を記載する。実際の配置・ネットワークは導入環境に合わせて更新する。

### 2.2 現行実装と計画の区別

| 項目 | 実装済み | 計画・未実装 | 根拠／確認方法 |
| --- | --- | --- | --- |
|  |  |  |  |
